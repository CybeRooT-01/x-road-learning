Un écosystème X-Road comprend **3 acteurs principaux**; comme on l'avais vu dans [[2- X-Road Ecosystem]]

### X-Road Operator

Gère l’écosystème :

- définit les règles ;
    
- accepte les nouveaux Members ;
    
- fournit le support ;
    
- exploite les composants centraux.
    

### X-Road Members

Organisations qui **produisent et/ou consomment des services**.

Un Member doit :

- suivre le processus d’intégration défini par l’Operator ;
    
- disposer d’un **Security Server**.
    

Un Member peut être **Provider, Consumer ou les deux**.

### Trust Service Providers

Fournissent les services de confiance nécessaires :

- **CA** → certificats ;
    
- **TSA** → horodatage.
    

Ils peuvent être des organismes externes ou être gérés directement par l’Operator.

### À retenir

`Operator → gère`

`Member → échange`

`CA → certificats`

`TSA → horodatage`
