3 acteurs principaux :

`Operator → Members → Trust Service Providers`

### X-Road Operator

Gère l’écosystème.

- Définit les règles
- Accepte les nouveaux membres
- Support
- Gère les composants centraux X-Road

### X-Road Members

Organisations qui échangent des services via X-Road.

Peuvent être :

- **Provider** : fournit un service
- **Consumer** : utilise un service
- **Les deux**

Chaque Member doit avoir un **Security Server** pour communiquer via X-Road.

### Trust Service Providers

Fournissent les services de confiance :

- **TSA** : horodatage
- **CA** : certificats numériques

Peuvent être externes ou gérés par l’Operator.

**À retenir :**

`Operator = gère`

`Member = échange`

`TSA / CA = confiance`
